ERH ICON LAUNCHER V4
1. Cài xong -> tự chuyển sang ERH.
2. Bấm icon đã cài -> tự chuyển thẳng sang ERH.
3. Không hiện launcher trung gian khi chạy từ icon.
4. Không sửa app ERH.
5. Chỉ đổi link tại launcher-config.js -> TARGET_URL.

Lưu ý: PWA start_url phải cùng origin GitHub Pages, nên launcher mở trước rồi redirect sang script.google.com.
